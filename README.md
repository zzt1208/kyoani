# 京都动画作品档案

一个离线浏览的京都动画作品与人物图鉴，收录 62 部作品、115 位主要角色，支持作品搜索/筛选/排序/分页，以及角色搜索、按作品筛选和角色详情查看。

## 使用

直接双击 `index.html` 即可，无需安装依赖或启动服务器。请保持目录结构不变。

## 文件结构

```text
index.html      页面结构
styles.css      样式
data.js         作品、角色、年表与图片路径数据
app.js          页面交互逻辑
assets/         本地图片资源
```

## 说明

- 作品与角色资料参考 Bangumi。
- 作品海报来自官方公开资料 / Bangumi，角色画像来自 AniList / Bangumi，版权归原权利人所有。
- 页面资源均为本地文件，正常浏览无需联网；外部作品链接除外。
